# Винная подборка

Скопируйте рядом с `app.py` собственные файлы `model.joblib`, `config.json` и `test.csv` вместо текущих. Модель - обученный sklearn-пайплайн StandardScaler → LogisticRegression без весов.

## Локальный запуск

Из папки wine_app:

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Вкладки

- Одно вино: 11 числовых полей и цвет вина; диапазоны и медианы из test.csv.
- Модельные метрики: матрица ошибок, precision, recall, F1, ROC и PR с текущей рабочей точкой.
- Пакетное предсказание: проверка обязательных колонок, числовых значений, пропусков и is_red; скачивание CSV с вероятностями, метками и порогом.
- Что выучила модель: коэффициенты стандартизованных признаков, отсортированные по значению.

Ползунок в сайдбаре общий для всех вкладок и хранится в session_state под ключом threshold. Решение — `p >= threshold`. Модельный порог был выбран на валидации; просмотр тестовых метрик в демо не даёт права подбирать по ним новый финальный порог.

## Почему два вида кэша

`st.cache_resource` хранит один общий объект модели на сервере между перезапусками скрипта и сессиями. Это подходит для загруженной модели: её не требуется копировать и приложение не меняет её состояние.

`st.cache_data` подходит для таблиц и массивов вероятностей: результаты сериализуются и возвращаются как отдельные копии, поэтому изменение таблицы одним пользователем не меняет кэш для других. CSV читается через load_test, вероятности — через test_proba. Параметр `_model` не хешируется; версия файла модели передаётся отдельно и обновляет кэш после замены файла. Порог не входит в ключ кэша вероятностей. При движении слайдера для теста выполняются только сравнение с порогом, расчёт метрик и отрисовка; predict_proba повторно не вызывается.

Без декоратора `joblib.load` выполнялся бы на каждом перезапуске скрипта, в том числе при движении ползунка: это лишнее чтение диска и десериализация модели.

Документация: https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_resource и https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_data
